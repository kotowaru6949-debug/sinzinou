# 阪神タイガース 新人王有資格者ドラフト ダッシュボード（2009〜2026年対応）

阪神タイガースの新人王有資格者を対象とした独自ドラフトゲームの結果および、2009年〜2026年（全18シーズン）の全新人王有資格者の中での「質と量」をスマホ・PCで閲覧・比較できるダッシュボードです。

## 🌐 公開ページ (GitHub Pages)
- https://kotowaru6949-debug.github.io/sinzinou/
- スマホで見やすいレスポンシブUI＋「LINEで友達に送る」「URLコピー」ボタン付き（特定年度を開いたURLをそのまま共有できます：`?year=2021`, `?year=all` など）。

## 📏 評価ルール（独自ポイント）
※対象は**1軍公式戦の成績のみ**（2軍成績は対象外）。
- **投手**：`1対戦打者 = 1ポイント`
- **野手**：`1打席 = 1ポイント`

## 📊 セイバーメトリクス指標（質と量）
各シーズンの `baseball-data.com` 1軍全選手データ（`tpa-1.html`, `ip3-1.html`）から算出したその年の1軍リーグ全体平均を `100` として質を評価しています。
- **投手**：対戦打者数（量） / K-BB実数（奪三振 − 与四球） / K-BB% / **K-BB+**（100=1軍平均）
- **野手**：打席数（量） / 塁打＋四球（生産量） / OPS / **OPS+**（100=1軍平均）

## 📁 ファイル構成
- `index.html`: マルチイヤー対応インタラクティブ・ダッシュボード（Chart.js 4象限散布図、仮想ドラフトシミュレーター、歴代Top30比較表、LINE共有機能）
- `history_data.json`: 2009〜2026年 全18シーズンの集計済みデータ
- `game_result.json`: 2026年ドラフト詳細データ
- `build_full_analysis.py`: データ取得（`--fetch-range`）・統合（`--merge`）・HTML生成スクリプト
- `.github/workflows/update.yml`: GitHub Actions 並列取得＆自動更新ワークフロー
