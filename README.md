# 12球団 新人王有資格者ドラフト ダッシュボード（2009〜2026年・全4,362名網羅）

2009年〜2026年（全18シーズン）の**12球団すべての新人王有資格者（野手2,017名・投手2,345名、延べ4,362名）**を網羅し、独自ドラフトルールとセイバーメトリクス指標（量×質）で分析・共有できるモバイル対応ダッシュボードです。

## 🌐 公開ページ (GitHub Pages)
- https://kotowaru6949-debug.github.io/sinzinou/
- 球団（`?team=阪神` 等）や年度（`?year=2021`, `?year=all` 等）を指定したURLを「LINEで友達に送る」ボタンでそのまま共有できます。

## ✨ 主な機能
- **12球団ピル切替 ＆ 選手名リアルタイム検索**：全12球団（`DeNA(横浜)`含む）の切り替え、0打席/0打者を含む全員／1軍出場／基準以上（投30打者・野20打席）フィルター、列ソートに対応。
- **2026年 阪神新人ドラフト結果**：独自ポイント（投手＝1対戦打者、野手＝1打席）での最終順位・内訳と12球団内での立ち位置を表示。
- **🎮 仮想ドラフトシミュレーター**：どの年度・球団でも好きな2人を選んでペア合計ポイントを試算できます。
- **質 × 量 4象限マトリクス**：投手（対戦打者 × K-BB+）、野手（打席数 / 塁打＋四球 × OPS+）を1軍平均ライン(100)付き散布図で可視化。
- **🏆 歴代比較（2009〜2026年）**：延べ4,362名を対象とした年度別総ポイント推移グラフと歴代ランキング。

## 📊 セイバーメトリクス指標（1軍リーグ平均＝100）
- **投手**：対戦打者数（量） / K-BB実数（奪三振 − 与四球） / K-BB% / **K-BB+**
- **野手**：打席数（量） / 塁打＋四球（生産量） / OPS / **OPS+**

## 📁 ファイル構成
- `index.html`: 12球団全選手網羅・スマホ対応ダッシュボード
- `history_data.json`: 2009〜2026年 全18シーズン・全4,362名分の集計データ
- `game_result.json`: 2026年ドラフト詳細データ
- `build_full_analysis.py`: データ取得・指標算出・HTML生成スクリプト
- `.github/workflows/update.yml`: GitHub Actions 自動更新ワークフロー
